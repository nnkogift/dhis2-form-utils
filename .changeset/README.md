# Changesets

This folder stores Changesets for coordinated releases of `@nnkogift/dhis2-form-utils-*`.

- Add one with `pnpm changeset` on your feature branch.
- Version bumps and publishing are handled by `.github/workflows/release.yml` on `main` / `beta` / `alpha`.
- See [docs/releasing.md](../docs/releasing.md) for channel setup and maintainer secrets.
